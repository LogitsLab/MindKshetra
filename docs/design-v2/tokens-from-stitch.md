# Tokens from Stitch (UI 2.0)

Locked visual DNA extracted from Stitch Flow v2 + master style.

## Color

| Token | Value | Use |
|-------|-------|-----|
| void | `#07090f` | App ground |
| field | `#0e1420` | Panels / elevated field |
| brass | `#c9a227` | Primary accent, CTAs, active tabs |
| brassSoft | `#e2c45a` | Soft gold highlights |
| teal | `#3d7a6a` | Atmosphere glow only — never buttons |
| text | `#eef2f7` | Primary |
| textSoft | `#c3ccd9` | Prose |
| textMuted | `#9aa8bc` | Chrome / labels |
| line | `rgba(201,162,39,.22)` | Brass borders on glass |
| hairline | `rgba(255,255,255,.06)` | Internal dividers |

## Type

- **Display / brand:** Fraunces (serif)
- **UI:** Sora (sans)
- **Sanskrit / Hindi:** Noto Serif Devanagari — never uppercase Devanagari

## Chrome

- App: 4 tabs Home · Explore · Mood · Astrology; Madhav brass FAB bottom-right
- Web: Explore · Mood · Practice · Astrology · Ask Madhav CTA · Account
- Home: practice-first — no streak/stats hero dashboard
- Progress / achievements: private Seeker path; grace-day streaks; no leaderboards

## Surfaces

- Glass / panel with thin brass border
- Photo path tiles with dark scrim + chevron
- Hairline list rows over card soup
